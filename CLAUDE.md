# JKV Global — Project Instructions

## Project

JKV Global is a premium institutional liquidity provider website.

## Objective

Build an original, world-class digital experience with
exceptional visual craftsmanship, storytelling, usability,
accessibility, and performance.

The website must not resemble a generic AI-generated
template or conventional fintech landing page.

## Existing Architecture

- Preserve the current Next.js project structure.
- Inspect package.json before recommending dependencies.
- Use TypeScript and existing Tailwind configuration.
- Do not modify Supabase schema, credentials, or backend
  integrations without explicit authorization.
- Never delete existing functionality without approval.

## Design Direction

- Premium, institutional, cinematic, sophisticated.
- Bespoke typography and carefully designed layouts.
- Refined motion and detailed visual interactions.
- Distinctive art direction across all pages.
- Avoid generic cards, excessive gradients, stock photos,
  repetitive layouts, and unnecessary visual clutter.

## Animation

- Use GSAP for complex cinematic timelines.
- Use Three.js / React Three Fiber for justified 3D scenes.
- Prefer lightweight CSS animations for simple interactions.
- Respect prefers-reduced-motion.
- Avoid unnecessary WebGL rendering and performance overhead.

## Installed Claude Tools

- frontend-design: use for frontend implementation.
- context7: consult for current library documentation.
- playwright: use for browser verification when available.

Verify tool availability before relying on any plugin.

## Development Workflow

1. Inspect the existing codebase.
2. Propose an implementation plan before major changes.
3. Work on one section or feature at a time.
4. Keep components reusable and maintainable.
5. Test responsiveness and functionality.
6. Verify visual quality with browser screenshots.
7. Review performance and accessibility.

## Quality Requirements

- Responsive desktop, tablet, and mobile experience.
- Semantic HTML and accessible navigation.
- Strong SEO and Core Web Vitals.
- Proper loading and error states.
- No fabricated regulatory, licensing, partnership,
  infrastructure, or execution-quality claims.

## Critical Rules

- Never replace the entire application unnecessarily.
- Never expose environment variables or secrets.
- Never modify production resources without approval.
- Do not generate the entire website in one step.
- Prioritize originality, trust, clarity, and craftsmanship.
